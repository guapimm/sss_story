## 7. 开发中踩过的坑（别重复）

| 坑 | 教训 |
|---|---|
| `field_validator` 校验依赖其它字段 | Pydantic 按**声明顺序**校验 → 必须用 `model_validator` |
| 里程碑用全书章号 | 模型不知道卷偏移 → 必须让它给**卷内序号**，代码换算 |
| 单层阈值 47/47 章全触发 | 闸门退化成"全部送审" → 必须**双层**（hard/target） |
| 细纲落实率用关键词精确匹配 | 正文会换语序 → 改用**字符 2-gram 包含率** |
| 桥接检测用整体 2-gram | 人名撞巧造成假阴性 → 改用**剔除虚词的实义 2-gram** |
| `triple_parallelism` 用简单正则 | 只得 2 处（baseline 60）→ 正确口径是「连续 ≥3 分句两两同构」 |
| 并行测试用耗时判定 | 全量负载下抖动 → 改用**区间重叠**的结构性判定 |
| 契约规则把整数 `prose_chars` 误判 | 规则本身要收敛（只看文本类型字段） |
| 契约规则用**子串**匹配 `os.environ` | 文档里提到该词也误报 → 改 **AST**。误报会诱人删解释性注释 |
| 配置里读了不存在的字段（`shadow`） | 只在真实运行时才炸 → 图测试必须**真跑**而不只验编译 |
| 手写阶段白名单（`queues` 只有 3 个） | 漏阶段 → 改由**枚举派生**（旧项目 `ACTIVE_PHASES` 漏 `architecting`） |
| 幂等键不含 `book_id` | 两本书共用 `thread_id` → checkpoint 串台 |
| 测试用"第 N 次调用返回第 N 个响应" | 多阶段并发时顺序不定 → 按**节点签名**分派 |
| `run()` 不返回 | 队列未 `close_all()` 时会一直等新单元（测试必须封口） |
