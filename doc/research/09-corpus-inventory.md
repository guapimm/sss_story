### 1.1 关键结论

- **`.rar` 无需安装任何东西**。`C:\Windows\System32\tar.exe` 是 bsdtar（libarchive），**原生支持 RAR5 解压**，实测 `tar -xOf 剑来.rar` 返回码 0、stderr 为空。
- **`.zip` / `.epub`** 用 Python stdlib `zipfile` 即可。
- **`.tar`** 用 Python stdlib `tarfile` 即可。
- 唯一缺口：**AES 加密 zip**（见 §5.3），stdlib 明确抛 `NotImplementedError: That compression method is not supported`。

### 1.2 ⚠️ bsdtar 读 RAR 的两个坑（必须处理）

1. **成员名是 GBK 字节**，不是 UTF-8。RAR5 头里没有置 UTF-8 标志，原始字节如 `bd a3 c0 b4 2e 74 78 74` 须按 **GBK/GB18030** 解码才得到 `剑来.txt`（按 UTF-8 解码会失败）。
2. **`-xOf` 输出流开头有固定 65514 字节的 NUL 前导**（疑似 libarchive 在管道模式下的稀疏/对齐伪影）。实测 3 个不同 rar 均为 **恰好 65514 个 `\x00`，且集中在开头 1 段**。剥离后长度与归档头声明的大小**完全一致**（例：`大奉打更人.txt` 声明 12434491 B，剥离后 12434491 B）。

> 正确读法：`subprocess.run([tar, "-xOf", rar]).stdout.lstrip(b"\x00")`

## 3. `.dzip` 格式逆向（本次调查的关键发现）

### 3.1 现象

5 个 `.tar` 的成员、2 个 `.zip` 的内层成员，扩展名都是 `.dzip`。其开头 16 字节为：

```
55 41 03 04 14 00 0e 08 08 00 00 00 00 00 00 00 ...
```

### 3.2 判定

这是**标准 ZIP，但全部 4 种记录签名被替换**：

| 标准 ZIP 签名 | `.dzip` 实际签名 | 记录类型 |
|---|---|---|
| `50 4B 03 04`（`PK\x03\x04`） | `55 41 03 04`（`UA\x03\x04`） | Local File Header |
| `50 4B 01 02`（`PK\x01\x02`） | `55 41 01 02`（`UA\x01\x02`） | Central Directory |
| `50 4B 05 06`（`PK\x05\x06`） | `55 41 05 06`（`UA\x05\x06`） | End of Central Directory |
| `50 4B 07 08`（`PK\x07\x08`） | `55 41 07 08`（`UA\x07\x08`） | Data Descriptor |

即 `PK` → `UA`（每字节 +5）。在样本中四种签名**各出现恰好 1 次**，是干净的一对一替换。
将其余字段按标准 ZIP 解释完全自洽：`method=8`（deflate）、`usize=475701`、`fnlen=37`、CRC 字段被清零（`flags=0x080e` 使用了 data descriptor）。

### 3.3 验证（已实测通过，非推断）

|---|---|
| `《一屋暗灯》…tar` | ✅ OK → 成员 `…（实体番）.txt`，773499 B，UTF-8 |
| `《可怜的s畜》…tar` | ✅ OK → 成员 `《可怜的社畜》…txt`，841570 B，UTF-8 |

**7/7 全部修复成功，且解出的文本经严格 UTF-8 解码零替换字符。**

### 3.4 标准修复代码

```python
import io, zipfile

SUBS = [(b"UA\x03\x04", b"PK\x03\x04"), (b"UA\x01\x02", b"PK\x01\x02"),
        (b"UA\x05\x06", b"PK\x05\x06"), (b"UA\x07\x08", b"PK\x07\x08")]

def open_dzip(blob: bytes) -> zipfile.ZipFile:
    for a, b in SUBS:
        blob = blob.replace(a, b)
    return zipfile.ZipFile(io.BytesIO(blob))
```

## 4. `.txt` 内容分析

### 4.1 编码判定矩阵

全部 **65 个载体**（含解压后的 txt）的整文件严格解码结果统计：

| 编码 | 文件数 | 说明 |
|---|---:|---|
| `utf-8`（无 BOM） | 34 | 整文件严格 UTF-8 通过 |
| `gb18030` | 22 | 整文件严格 GB18030/GBK 通过 |
| `utf-8-sig`（有 BOM `EF BB BF`） | 8 | 必须用 `utf-8-sig` 读，否则首字符带 `\ufeff` |
| `utf-16`（BOM `FF FE`） | 1 | 见下 |

- **替换字符总数 = 0**（65/65 文件）。即：**没有任何一个文件需要 `errors="replace"`**，全部可无损解码。

- 无 `big5` 文件（全部样本 big5 严格解码均失败）。
- 判定方法：读**整文件**做严格解码，不用 200KB 截断——截断会把多字节字符切断而产生假阴性（本次调试中 `《判官》` 就曾因 200KB 边界被误判）。

### 4.3 章节标记规律（核心产出）

**主导正则（覆盖绝大多数文件）：**

```python
r"^[ \t\u3000]*(?:[☆★◇◆]\s*[、.]?\s*)?(?:\d{1,5}\s*[、.．]?\s*)?第\s*[0-9零一二三四五六七八九十百千万两〇]+\s*[章回节]"
```

## 8. 附：完整读取实现参考（stdlib + bsdtar，无第三方依赖）

```python
import io, os, re, subprocess, zipfile, tarfile

TAR = r"C:\Windows\System32\tar.exe"
SUBS = [(b"UA\x03\x04", b"PK\x03\x04"), (b"UA\x01\x02", b"PK\x01\x02"),
        (b"UA\x05\x06", b"PK\x05\x06"), (b"UA\x07\x08", b"PK\x07\x08")]

def _undzip(blob: bytes) -> bytes:
    for a, b in SUBS:
        blob = blob.replace(a, b)
    return blob

def _first_member(blob: bytes) -> bytes:
    with zipfile.ZipFile(io.BytesIO(blob)) as z:
        for i in z.infolist():
            if not i.filename.endswith("/"):
                return z.read(i.filename)
    raise RuntimeError("empty archive")

def read_book(path: str) -> bytes:
    """返回书籍正文的原始字节（不含容器）。只读，不落地任何文件。"""
    ext = os.path.splitext(path)[1].lower()

    if ext == ".txt":
        return open(path, "rb").read()

    if ext == ".rar":
        # bsdtar 读 RAR5；成员名 GBK；输出有 65514B NUL 前导
        out = subprocess.run([TAR, "-xOf", path], capture_output=True, check=True).stdout
        return out.lstrip(b"\x00")

    if ext == ".tar":
        with tarfile.open(path, "r:*") as t:
            inner = t.extractfile(t.getmembers()[0]).read()
        return _first_member(_undzip(inner))          # .dzip → ZIP → txt

    if ext == ".zip":
        with zipfile.ZipFile(path) as z:
            for i in z.infolist():
                if i.filename.endswith("/"):
                    continue
                data = z.read(i.filename)
                return _first_member(_undzip(data)) if data[:2] == b"UA" else data

    if ext == ".epub":
        # 需另做 HTML 去标签（见 §3.5-D）
        return b""

    raise ValueError(f"unsupported: {ext}")

def decode_any(blob: bytes) -> tuple[str, str]:
    """整文件严格解码，返回 (文本, 编码名)。不产生替换字符。"""
    if blob[:3] == b"\xef\xbb\xbf":
        return blob.decode("utf-8-sig"), "utf-8-sig"
    if blob[:2] in (b"\xff\xfe", b"\xfe\xff"):
        return blob.decode("utf-16"), "utf-16"
    try:
        return blob.decode("utf-8"), "utf-8"
    except UnicodeDecodeError:
```
