## ★ 正向着色（D-08 的核心，方向与旧项目相反）

| | 旧项目 | 本设计 |
|---|---|---|
| 空实现写在哪 | **story 侧**给 learn 写（`story_flow.py:171-201` **8 个** `@staticmethod`）| **learn 侧**为自己占位 |
| 调用结果 | 返回 `""`/`[]` —— **静默出错** | `raise`，带实现指引 |

**哪个能力** · **哪个模式** · **怎么办**。

## 双向矩阵契约测试（本阶段的核心交付）

"story 不实现 learn 专属能力"与"learn 不实现专属能力"**两个方向都断言**。
只测一边会漏掉反向回归 —— 例如有人为"让 learn 能跑"给 story 加空实现，
**那正是旧项目的形态**。

`scripts/mutate_mode_matrix.py` **三次真变异全部拦下**：

| 变异 | 模拟的缺陷 | 结果 |
|---|---|---|
| 给 story 加 `ledger` 空实现 | 旧项目 `story_flow.py` 的 8 个空实现 | 拦下 ✓ |
| 给 learn 挂 `ledger` 属性 | 破坏"取的时候就炸"，退化成"调用时才炸" | 拦下 ✓ |
| `_BUILDERS` 删掉 learn 登记 | 同类：`PipelineStage.CHAPTER` 枚举有、映射没有 | 拦下 ✓ |
| 还原后复验 | — | 通过 ✓ |

## PromptPack 的 pack 维度（learn 的 P1 单点前提）

`_load(name, *, pack="")`：`pack=""` → `prompts/x.md`（story 既有路径
**零改动**）；`pack="learn"` → `prompts/learn/x.md`。

★ **关键设计**：pack 子目录不存在时**抛错**，不静默回落默认 pack ——
回落会让 learn 悄悄沿用"对话占比 ≥25%、比喻要少"的散文规范，
而教学章"不要对话、比喻是教学手段"是**正确**写法。

## 数据移植（数据与代码分离）

| 数据 | 来源（权威） | 结果 |

（prompt 文本含模式专属措辞）。故 TOML 里 grand 共享写顶层，
其余分模式 —— 避免两份重复数据漂移。

`['fast','grand','learn','standard']` —— 把另一个模式的**名字**当成了档位名
（因为 `[learn]` 是顶层 dict）。已加测试 `test_all_scales_does_not_leak_other_mode_name`。
