### 2-2 · 联网研究

`infra/retrieval/` 此前 **0 字节**，现建成三个模块：

| 文件 | 职责 |
|---|---|
| `provider.py` | Tavily 真检索 + Mock 占位（**显式构造**，无运行期分支） |
| `store.py` | TTL **真的生效**的缓存 + 分阶段断点 |
| `research.py` | ★ **按知识点目标驱动的多轮编排** |

**触发判据**（用户："一次不够后续动态补充"）：

    ① 目标知识点数按篇幅档位（fast 8 / standard 25 / grand 60 / ultra 150）
    ② 每轮换检索角度（6 个模板，教学自然顺序：
       是什么 → 怎么来 → 误区 → 应用 → 前沿 → 与相邻领域关系）
    ③ 达标即停；不够继续；**角度用尽如实报告缺口**，不硬凑

依据：旧项目 `estimator.py` 用 `points_count` 推章数（约 4 章讲 1 个知识点）。

**两处刻意与旧项目不同**：
1. **不做"按 key 自动降级"** —— 旧项目 `if key else Mock` 是运行期分支，
   会让"有没有 key"**静默改变行为**。改为唯一工厂，Mock 结果带
   `[Mock]` 前缀 + 空 URL（**可识别**）。
2. **TTL 真的生效** —— 旧项目有配置键但 `get()` 不检查。

**可视化**：

**「能编辑 + 回退」的实现**（用户明确要求）：

| 行为 | 实现 |
|---|---|
| 逐条确认 | `accept --mappings "函数" "循环"` 只确认指定条目 |
| 改完自动取消确认 | `edit` 后该条 `accepted=False`，**且不连坐其它条** |
| 版本化 | 每次改动前存 `history/map_NNN.json` |
| 回退 | `rollback --revision N` **同时恢复内容与确认状态** |
| 回退本身可回退 | 回退前先存档当前版本 |

**命令清单**：
```powershell
uv run storyforge learn-map gen      --book-id 31 --topic "宋代点茶" --scale fast
uv run storyforge learn-map show     --book-id 31 [-v]
uv run storyforge learn-map accept   --book-id 31 --points            # L-1
uv run storyforge learn-map accept   --book-id 31 --mappings "函数"    # L-2 逐条
uv run storyforge learn-map edit     --book-id 31 --term "函数" --replacement "本命功法"
uv run storyforge learn-map reject   --book-id 31 --term "循环"
uv run storyforge learn-map history  --book-id 31
uv run storyforge learn-map rollback --book-id 31 --revision 4
```

**校验（零 LLM，6 条判据，每条对应实测过的失败形态）**：
空知识点集 / `point_id` 重复（跨章引用指错）/ 术语重复（说法歧义）/
空壳条目 / **说法与原术语相同（等于没平替）** / **无来源（可能是幻觉）**

★ 确认前**必须过校验** —— 有问题的地图不能被盖章通过（它是世界观的输入）。

### 两次"拆文件而非放宽规则"（cli.py 两次撞 800 行）

契约规则 10（单文件 ≤800 行）是**为旧项目 `pipeline.py` 8,607 行立的**，
所以撞限时的正确反应是拆，不是放宽：

  1. 加 `flows` 命令后 → 拆出 `doctor.py`（161 行）
  2. 加 `research` 命令后（798/800）→ 拆出 `commands/learn.py`

★ 第一次拆分时我**凭记忆重写** `run_doctor` 而非逐字搬运，
引入两个真 bug（`reg.models.items()` 类型错、误删仍在用的 import），
被 `doctor: FAIL` 与 traceback 抓到 →
新增 `scripts/verify_doctor_parity.py` 验证 10 项体检项逐项一致。
**教训：纯搬运式重构必须逐字复制。**

### 测试写错两次（也值得记）

- `test_mapping_roundtrip` 初版写 `LearningMap(**m.to_dict())` —— 错的：
  `to_dict()` 产出嵌套 dict，不是领域对象。真正走的是
  `commands/learning.py:_from_dict`。**测了一个不存在的路径。**
- `test_rollback_to_nonexistent_version_fails` 初版没先制造历史，
  于是测到的是"没有历史版本"分支（另一条测试的分支）。
